# Brand Revenue Performance Dashboard

A visual analytics interface comparing the five-year annual revenue trajectories of global footwear and apparel leaders: **Nike, Adidas, Under Armour, Vans, and Converse**. This project plots financial datasets on an interactive multi-line graph to highlight shifting consumer trends and market share distribution.

## 📊 Core Dataset (2021 - 2025)

The dashboard visualizes the following absolute financial metrics, scaled uniformly in **Billions of USD**:

* **Nike:** Peak performance hovering above the $51B milestone, maintaining a dominant market lead despite recent macroeconomic pressures.
* **Adidas:** A robust second-tier anchor capturing consistent multi-billion dollar athletic sectors, demonstrating a sharp strategic recovery trajectory by 2025.
* **Under Armour:** Representation of the mid-tier performance athletic segment, documenting structural pivot phases and shifting volume adjustments.
* **Vans:** Lifestyle action-sports performance tracking the broader consumer retail cycles within its parent firm portfolio.
* **Converse:** Core classic footwear segment, providing a steady baseline metric of heritage cultural footwear sales.

## 🛠️ Key Visual Features

* **Proportional Scaling:** The interface explicitly starts scales at zero to accurately convey the massive market-share delta between industry giants and mid-tier retail brands.
* **Custom Brand Themes:** Every corporate dataset maps to recognizable brand identifier colors (e.g., precise dark hues for Nike, athletic blue variations for Adidas) to ensure clear, split-second readability.
* **Responsive Breakpoints:** The layout container uses percentage-based scaling boundaries to guarantee crisp font scaling and legend rendering across desktop, tablet, and mobile views.
* **Smoothing Modifiers:** Soft Bezier anchor modifications are implemented to separate overlapping intersection metrics without distorting actual performance milestones.

## 🚀 Deployment Requirements

To load and interact with this project locally or on a live web server, ensure you have:
1. A standard web browser environment (Chrome, Safari, Firefox, Edge).
2. Active network access to fetch the rendering framework from its respective public Content Delivery Network (CDN).
3. The structural markup document linked directly to its companion graphics configuration matrix script.
